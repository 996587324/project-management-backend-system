# 工作任务选择窗体：修改与验证

日期：2026-10-28。

## 本次修改

- 任务编辑始终显示主责员工。草稿可选择工作组内具有执行资格的员工；正式任务回显当前员工，提供明确的“更换主责员工（转派）”入口。
- 正式任务的工作组和主责员工不再通过变更要求直接修改；后端同步拒绝这种绕过责任交接的请求。
- 工作组、主责员工、验收人、汇总负责人、管理责任交接、设置中的成员/授权人员和授权对象，改用选择窗体。
- 人员按姓名或账号搜索，分页加载；不同选择用途在后台分别验证候选资格，不再允许随意输入不存在或不合资格的账号。
- 表格展示名称、账号、工作组、可选状态与原因；历史负责人停用或失去资格时，保留选值回显及说明。
- 多选组件支持跨页保留、全选当前页、全选全部筛选结果、全不选、已选项移除及确认/取消；工作日配置使用同一多选窗体。
- 少量固定选项如优先级、状态、角色类型继续使用原控件。主责员工仍为单选，本次没有改变成多人共同主责。
- 新增受权限控制的候选人员接口，不新增数据库表，也不改变原项目任务模块。
