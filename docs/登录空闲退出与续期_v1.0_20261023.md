# 登录空闲退出与续期

实现日期：2026-10-23。适用于后台控制台及 A/B 管理入口。

## 用户体验

- 连续 20 分钟无操作退出，最后 1 分钟弹窗显示秒数。
- 真实鼠标操作、键盘输入、滚轮或触摸更新最后操作时间；“继续使用”同样重新计时。
- API 轮询、在线统计心跳、WebSocket 心跳、自动刷新、程序滚动、仅聚焦窗口不算操作。
- 同会话的同源标签页共享操作及退出标记；不同源 A/B 通过服务器同步会话截止时间。
- 刷新不重置计时。休眠恢复后先检查有效期，过期后的点击不能重新激活登录。
- 已发布的公开只读大屏不显示后台空闲提示、不因交互续期；后台会话清理后保留公开页面。
- PDA 的原有登录机制不参与此改造。

## 实现

前端：

- `src/utils/auth/idle-session.ts`：独立状态机、20 分钟计时、最后 1 分钟提醒、请求节流及旧响应隔离。
- `src/components/business/session-idle-warning/index.vue`：全局提醒、可信交互监听及会话 API 适配。
- `src/App.vue`：挂载全局组件。
- `src/store/modules/user.ts`：主动退出共享标记；公开页面清理会话时可保留路由。
- `src/utils/system-applications/client.ts`：读取令牌会话标识和到期时间。

后端：

- `SystemApplicationService.GetSessionActivityAsync`：只读状态与真实操作续期。
- `GET /api/system-applications/session`：查询服务器时间、截止时间；不延长会话。
- 该只读接口使用独立 `SessionStatus` 鉴权方案：仍校验签名、签发方、受众、会话、账号和授权；允许已过期的浏览器令牌在其他 A/B 页面仍保持会话有效时换新。过期/撤销的数据库会话不能恢复，旧令牌不能直接访问业务接口或提交操作续期。
- `POST /api/system-applications/activity`：请求体 `{ "idleMilliseconds": 0 }`，表示最后真实操作距发送请求的毫秒数。必须小于 1200000 且非负。
- 返回 `sessionId`、ISO UTC 格式的 `serverTimeUtc`/`expiresAtUtc`、`idleTimeoutSeconds`，及需要更新时的 `token`/`portalToken`。
- 服务器在有效会话上按“服务器当前时间 + 20 分钟 - 空闲时长”续期；条件更新不恢复已过期/撤销会话，也不缩短其他页面已延长的有效期。
- 令牌临近到期时轮换，保持原系统及用途；控制台凭据一并更新。浏览器令牌可比会话晚 5 分钟到期，但每次鉴权仍检查数据库中的会话有效期。
- Axios 和系统入口请求在发送前检查令牌时间；挂起页面先通过只读接口更新旧令牌，避免唤醒后的并发请求误触发退出。
- 不修改表结构，沿用 `SysPortalSession.ExpiresAtUtc`；原在线审计心跳不参与授权续期。

正常每 15 秒同步一次，只在存在尚未上报的真实操作时 POST，否则 GET。临近到期的操作立即提交；切后台或关闭页面时补发节流窗口内的操作。网络失败不会冒充服务端续期；恢复连接时仍以有效会话为准。

## 验证与使用

- 前端自动回归：`pnpm exec tsx scripts/test-idle-session.ts`。

- 后端回归：`tests/MultiSystemSmoke`，在随机隔离数据库验证真实 SQL、HTTP、JWT、A/B 授权、并发续期及精确过期边界，完成后删除隔离库。
