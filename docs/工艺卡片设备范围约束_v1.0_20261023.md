# 工艺卡片设备范围约束

日期：2026-10-23

## 使用规则

- 卡片的字段数据源、公式变量，只能选择所属工艺线体已关联且当前账号已授权的设备。以完整租户标识和设备标识精确匹配。
- 线体未关联设备时，卡片禁用设备选择，并提示先在线体配置中关联设备。固定文本、固定数值仍可使用。
- 新建卡片切换所属线体后重新检查已有字段，不自动清空配置；越界绑定需要调整后才能保存。
- 历史卡片的越界绑定保留并提示。只有原卡片、原字段、原绑定位置、原租户/设备/字段路径完全不变时可继续保存；新增字段、修改路径、重命名变量或复制为新卡片不能沿用此例外。
- 从线体移除设备时，如任一卡片仍在引用该设备，则阻止保存，并列出卡片及字段/变量。停用卡片也会检查。
- 线体自身的独立曲线字段维持原有选取方式；本次约束针对线体下面的参数卡片。

## 实现位置

前端 `project-management-system`：

- `src/views/process-board/components/device-scope.ts`：设备身份、字段/变量引用及历史例外判定。
- `SourceBindingEditor.vue`、`ParameterFieldEditor.vue`：主字段和公式变量传入线体范围，保留越界旧值并提示，固定值不受影响。
- `src/views/process-board/config/index.vue`：卡片保存前检查、线体设备移除提示。
- `src/components/business/source-tree-select/index.vue`、`src/api/source-catalog.ts`：可选查询参数 `processLineId`，沿用原有响应失效保护。

后端 `project-management-backend-system`：

- `Service/ProcessBoard/ProcessBoardDeviceScope.cs`：保存时读取真实父线体并校验卡片，以及移除设备时检查所有子卡片。
- `ProcessBoardService.SaveAsync` 统一执行约束，包含 Agent 写入。沿用现有数据库锁，串行处理设备移除与新绑定，避免并发留下越界引用。
- `SourceCatalogService` 对 `processLineId` 校验线体访问权限，在搜索、模型统计、分页和精确回显之前取账号设备权限与线体设备的交集。此参数仅适用于 `purpose=process`、`kind=Realtime`。

无数据库表结构变化，无需迁移。历史越界绑定的运行行为保持兼容，未批量清理或改写已有配置。
