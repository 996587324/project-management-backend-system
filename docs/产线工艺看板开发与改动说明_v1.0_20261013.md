# 产线工艺看板开发与改动说明 v1.0

日期：2026-10-13。本文是独立新增文档，不覆盖既有需求或迭代文档。

## 1. 本次业务范围

新增独立的工艺参数看板：区域 → 工艺线体 → 工艺流程、参数卡片和线体曲线。

- 区域、线体、卡片配置独立于原生产监控和设备卡片；原来的配置不迁移、不覆盖。
- 卡片展示 Key、Value、单位和上下限圆点，不统计设备在线/离线状态。
- 数据源、历史字段目录、通用中文映射及字段最新值持久化继续复用。
- 支持固定文本、固定数值、跨设备字段和数学公式；每个字段可独立开启趋势、追溯、微信推送。
- 线体可设置独立曲线参数，不要求这些参数出现在展示卡片内。

## 2. 使用入口

后台“产线看板”目录下新增：

| 名称 | 路由名称 | 默认地址 | 前端组件 |
| --- | --- | --- | --- |
| 产线工艺看板 | ProcessBoard | /production-dashboard/process-board | src/views/process-board/board/index.vue |
| 工艺看板配置 | ProcessBoardConfig | /production-dashboard/process-config | src/views/process-board/config/index.vue |

后端启动时仅补缺失菜单，不覆盖已有名称、排序、启停。A 增加菜单关联；B 已开放产线目录时补独立菜单实例，否则可从系统入口与授权的业务组件目录选择添加。没有登录、业务权限或资源授权不能调用接口。

建议配置顺序：

1. 新建区域。
2. 新建独立工艺线体，选择所属区域，关联设备。
3. 新建参数卡片，选择工艺线体，配置展示字段。
4. 需要曲线时开启字段的曲线采样，或在线体配置中新增独立曲线字段。
5. 在“流程 / 布局”入口配置节点、连线、关联卡片和排列方式。
6. 需要微信通知时选择已绑定用户和触发条件，检查推送记录。

区域与线体切换会更新地址查询参数，可以保存区域或线体的进入链接。页面刷新、返回上一级和下拉切换均保留明确导航层级。

## 3. 公式与个人使用配置

NuGet：MathParser.org-mXparser 6.1.1。

没有四则运算白名单；数学函数、常量、条件、求和、积分等交由 mXparser 解释。支持变量绑定、自定义数学函数和常量。不执行 SQL、C#、JavaScript，不注册访问系统资源的 CLR 扩展函数。

### 配置位置

“工艺看板配置 → 采样与发送 → mXparser 授权配置”：

- 使用类型默认 `Personal`（个人非商业使用）。
- 使用者署名需填写真实名称。
- 确认条款后，后台调用 `License.iConfirmNonCommercialUse(署名)`。
- 商业模式调用 `iConfirmCommercialUse`，前提是确实已经取得适用的商业授权；勾选不是购买授权。
- 未确认条款不执行业务公式，返回明确提示；不使用公式的原始字段展示不受影响。

企业内部、生产经营或公司部署不能仅因为选“个人”就视为合法非商业使用。官方说明：

- https://mathparser.org/mxparser-tutorial/confirming-non-commercial-commercial-use/
- https://mathparser.org/mxparser-license/

数据库保存的授权配置是业务执行的唯一来源。`ProcessBoard:Formula:TimeoutSeconds` 可通过现有 .NET 配置机制调整隔离计算预算，默认 5 秒，范围 1～30 秒。本次没有修改现有 appsettings.json 或环境密钥。

### 输入与结果

- `x` 是当前原始值，可增加其他变量并绑定不同设备字段或固定数值。
- 常量使用 JSON，如 `{"target":100}`，变量和常量不能重名。
- 自定义函数每行一个定义，例如 `f(a)=a^2+1`。
- 前端测试变量使用 JSON，如 `{"x":25,"actual":80}`。
- 原始输入、计算值、来源时间及配置版本一起保存；历史不会随新公式重算。
- 引擎返回 double，不是精确 decimal。显示精度和业务比较精度分别配置，默认比较精度 6 位。数值与上下限按同一比较精度归一化，阈值差值也采用该精度。
- NaN、Infinity、缺少变量、除零和语法错误返回异常信息，不改成 0。

公式在独立子进程执行，最多并行两个进程；超时会终止子进程，不能占住登录和菜单请求。子进程分支在创建 WebApplication 之前退出，不连接数据库、不启动后台服务。

公式输入未变化时复用持久化结果。随机或需每轮重新计算的表达式可开启“采样时重算”。每轮采样开始至计算完成有实际耗时，采样间隔不是硬实时保证。

## 4. 实时值、状态及追溯口径

展示前复用字段级最新值存储。增量消息不包含某字段时保留该字段最后实际值；明确上报 null 或替换父结构时按原最新值存储的语义清空，不凭空补 0。

圆点：小于下限或大于上限为红色，范围内为绿色，无范围或无有效数值为灰色。默认判断计算后的展示值；等于归一化后的边界为正常。它不是在线状态。

追溯阈值以最后一次追溯基准累计比较，低于阈值的变化不会重置基准。文本内容变化不使用数值阈值。阈值为 0 时有效值变化即触发。

初次有效超限可以生成事件；持续处于同一超限状态不反复生成越界事件；明确空值不是“恢复正常”。变化事件、越界事件、恢复事件可以记录并按条件推送。没有开启追溯但启用了推送时，仍保留推送触发事件用于审计。

配置采用版本检查，避免并发覆盖。布局修改不重置相同字段的变化基准。配置更新后的未发送任务会重新校验版本、启停、接收人及微信绑定，旧任务可能被取消。

## 5. 布局与曲线

- 区域内线体支持网格、横向或纵向排列及宽高配置。
- 参数卡片支持网格、横向、纵向和自由定位。自由定位模式拖动标题移动，右下角调整宽高；其他模式可调整排序和每行数量。网格宽度优先响应式列布局。
- 线体流程图支持节点移动、连线、缩放、平移、节点关联卡片，展示时双击定位卡片。
- 流程区和曲线区支持独立高度、宽度；宽度 0 为自适应。曲线可以标签切换或与卡片同屏。
- 小屏优先响应式布局；自由定位画布保留配置并允许滚动，不强行重排保存坐标。
- 实时刷新不重置布局和流程缩放；查看模式没有编辑按钮。

曲线按设备分组选择参数。单次最多 12 条曲线，按单位分轴；支持滚轮、框选和时间滑块缩放，支持原始值/展示值切换。双击设备/参数或曲线可打开明细。

趋势采样与变化事件分开；后台持续采样不依赖浏览器是否打开。查询默认最近五小时，可以更改时间范围。服务器按时间桶聚合均值、最小值、最大值和样本数；图线绘制桶均值，明细和导出保留原始样本，不把聚合值当作真实逐条记录。

## 6. 存储、保留与导出

| 表 | 用途 |
| --- | --- |
| ProcessBoardConfig | 区域、线体、卡片定义，父级、版本、启停及 JSON 配置 |
| ProcessBoardValue | 字段最新计算结果、追溯基准、最近有效上下限状态 |
| ProcessBoardSample | 连续采样，包括原始数值与计算数值列及完整运行快照 |
| ProcessBoardEvent | 变化、越界、恢复事件 |
| ProcessBoardConfigAudit | 配置版本与修改人；全局设置使用 ConfigId=0 |
| ProcessBoardSetting | 采样、保留及公式授权配置 |
| ProcessBoardExport | 用户、所属系统、时间范围、文件及异步导出状态 |

本期使用 SQL Server 普通索引表，不使用软删除、Redis或新的消息中间件。采样索引覆盖字段、时间和数值列，曲线不需加载完整 JSON 后计算。

默认采样间隔 5 秒、历史保留 120 小时，可修改为 1～8760 小时；每五分钟分批硬删除过期采样和事件，每轮每类最多删除 4 万条，积压分轮继续。最新值及配置审计不跟随实时历史删除。

导出是后台任务：一次最多 100 万行、64 MB，同一用户最多三个待处理任务；按 Id 游标每批 1000 条生成 CSV，不在前端拼接全部数据。超限明确提示缩小范围或按参数分批，不继续生成超大文件。创建任务锁定当前最大记录 Id，后续新增记录不混入已创建导出。

导出只允许原创建用户、原 A/B 系统下载，下载时再次检查线体和来源权限。未完成时间允许 SQL NULL。文件默认保留一天，过期清理文件；进行中的导出时间范围短期保护，防止历史清理截断文件。文件位于应用目录下 data/process-board-exports。

普通 HTTP/IP 访问下载时仍携带 JWT；支持安全环境的文件流保存，HTTP 环境走已有授权下载回退。没有通过 URL 暴露 JWT。

## 7. 微信队列复用

仍使用原 EdgeDeviceCardPushTask 和队列设置，不另外启动独立发送循环。

- 工艺任务用负 CardId、负 RuleId（配置版本）和 `process:线体ID` 标识，与原正数设备卡片区分。
- 相同微信绑定的接收人按现有聚合规则合并；队列全局租约和发送间隔仍生效。
- 失败、未知结果、绑定改变及配置停用沿用现有发送状态处理。
- 本次没有真实发送微信消息；验证只创建隔离库的队列记录及检查配置有效性。

## 8. A/B 权限

菜单权限为 ProcessBoard（查看）和 ProcessBoardConfig（配置）。

新的工艺线体不是旧生产线体。资源授权沿用现有授权集合的独立命名空间：在“允许线体”中填写 `process:ID`，例如 `process:12`；ID 在工艺配置列表查看。旧线体编码 L1 不会授权工艺线体 L1。

非全部资源用户还需要对应 `租户|设备` 的实时来源授权。运行值、历史、导出和推送记录再次检查来源权限；历史来源绑定变更后，不向只持有当前来源授权的用户泄漏旧来源值。

创建区域或新线体需要全部资源授权及配置权限；普通配置用户只能编辑获授权线体及其卡片。全局采样、公式授权及共享发送间隔仅平台管理员可修改。
