# 设备模型映射关联上报模型

日期：2026-10-23。

## 当前行为

入口：产线看板配置 → 设备模型映射。

- 列表合并“授权实时设备最新快照中的模型”与“已保存的共享名称映射”，显示已配置/未配置、授权设备数量和最近接收时间。
- 未配置模型排在前面，支持按模型标识、中文名称搜索，以及按配置状态筛选；列表每页 20 条。
- 可直接点击已上报模型的“配置映射”，自动带入原始 modelMark。
- 新增时支持搜索选择上报模型；也保留手动输入编码，方便设备接入前预配置。
- 选择已有映射时恢复原配置，包括名称、类别、排序、停用状态，避免重复新增。
- 保存后按原模型编码关联；删除后只删除映射，仍存在于快照中的模型恢复为未配置。
- 已保存但暂无设备数据的预配置继续显示，设备数量为 0、接收时间为“—”。
- 缺失 modelMark 的设备仍显示“未提供模型标识”，不能据此新建具体模型映射；需由上报端补充标识。
- 中文名称和类别由用户填写，不根据模型代码自动猜测，不在接收报文时自动写入或启用字典。

## 数据与权限

- 使用 `/api/source-catalog/models?purpose=dashboard&kind=Realtime` 分页读取模型，完整加载所有页面，避免前 100/500 条截断。
- SourceCatalogModel 增加可选 `latestReceiveTime`，在已授权设备范围内计算 MAX(ReceiveTime)，与设备计数采用相同过滤条件。
- 旧模型目录、设备树仍兼容额外字段；中转订阅不使用配置更新时间冒充接收时间，其接收时间为空，模型仍未分类。
- 保留原配置页和共享映射写入权限约束；本次没有扩大旧配置接口的数据范围或修改共享字典授权规则。
- 复用原共享模型映射表，没有新增实体列或结构迁移，没有改变原始上报数据、设备绑定和统计规则。
